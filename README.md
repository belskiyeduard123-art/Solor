# СолорЭлектро

Сайт-визитка ООО «СолорЭлектро» (Минск) — электромонтажные работы и инженерные
системы под ключ. Статическая страница без сборки и зависимостей: чистые HTML,
CSS и JavaScript.

Рабочий сайт: <https://solorelektro.by/>

## Структура

```
index.html           единственная страница сайта
assets/styles.css    стили
assets/main.js       мобильное меню, форма заявки, кнопка «наверх»
public/images/       изображения, логотип и иконки
favicon.ico          иконка вкладки
site.webmanifest     манифест веб-приложения
robots.txt           правила для поисковых роботов
sitemap.xml          карта сайта
```

## Запуск локально

Сборка не нужна — достаточно открыть `index.html` в браузере.

Часть возможностей (манифест, пути от корня сайта) работает корректно только по
протоколу `http://`, поэтому для проверки удобнее поднять локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000/>.

## Разделы страницы

- **Наши услуги** (`#services`) — перечень направлений работ
- **Как мы работаем** (`#steps`) — этапы сотрудничества
- **Получите бесплатную консультацию** (`#contacts`) — форма заявки и контакты

## Правка контента

Тексты, телефоны и адрес находятся прямо в `index.html`. Контактные данные
продублированы в блоке микроразметки `application/ld+json` в `<head>` — при
изменении телефона или адреса обновите оба места, иначе поисковые системы
будут показывать устаревшие данные.

Форма заявки отправляется через [Formspree](https://formspree.io/) — адрес
указан в атрибуте `action` тега `<form id="leadForm">`. Валидацию полей,
обработку ответа и тексты сообщений см. в `assets/main.js`.
